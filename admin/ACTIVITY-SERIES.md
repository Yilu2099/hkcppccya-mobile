# 活动系列标签使用说明

此说明对应本次代码修改；合并和生产部署验收完成后生效。正式后台：https://hkcppccya.org/cms/

## 给一篇文章设置或清空标签

1. 左侧打开「消息与报道」，搜索文章并点开。
2. 在顶部「基本信息」中找到「活动系列（日期旁标签）」。
3. 选择需要的系列；不需要标签时选「不显示标签」。
4. 点击「保存修改」，再打开官网「活动回顾」核对。此选择同时决定文章归入哪个重点活动系列；清空后不再归入四大系列，但文章仍保留在活动回顾中。

列表中的日期和文章分类后也会显示当前活动系列，便于检查。文章分类（活动消息／报道及专访）与活动系列是两个独立选项。

## 统一修改标签文字

1. 左侧打开「页面文字与标签」。
2. 顶部「活动系列与标签名称」默认展开，点开对应系列。
3. 修改「标签文字（日期旁）」并点击「保存修改」。
4. 这个系列的所有文章标签、活动回顾筛选文字会一同更新；文章编辑器下次打开时也显示新名称。

「活动页名称」控制重点活动页面的完整名称，可以与较短的标签文字不同。例如「青年導師計劃」是完整名称，「青年導師」是标签。保留现有四个系列，不增加分类管理页面。
